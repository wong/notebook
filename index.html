公开标题

显示在锁屏封面和浏览器标签页上，未加密，任何人可见。

修改主密码

用新密码（新的随机 Salt）重新加密全库。修改后需「发布」或下载新文件才会在线上生效。忘记密码无法找回。

通道 A：GitHub API 一键发布

用户名、仓库等信息会加密同步进笔记本，换设备解锁后自动带出。Token 默认只保存在本机，绝不会以明文写入 HTML。建议使用只授权该仓库、仅 Contents 读写权限的 Fine-grained Token。

仓库信息总会加密同步。勾选后，Token 会用主密码加密写进 index.html，安全性取决于主密码强度；请确保 Token 只授权 notebook 这一个仓库。不勾选时 Token 只保存在本机。

通道 B：手动保底

生成包含最新密文的完整 index.html，手动覆盖到 GitHub / Netlify / Cloudflare Pages。

导入 Joplin 笔记

Joplin → 文件 → 导出全部 → 「MD - Markdown + Front Matter」。选择导出的整个文件夹：子文件夹名作为笔记本分类，_resources 中的图片会自动匹配、压缩并加密内嵌。

手机浏览器不支持选择文件夹时，可用第二个按钮同时多选 .md 文件和图片文件，图片会按文件名自动匹配（此时笔记统一归入「默认笔记本」）。

按年份归档（容量自动扩展）

主文件预计超过 13.5 MB 时，每次发布前会自动把最早年份（不含今年）的笔记移到独立的 archive-年份.html，直到主文件降到 10 MB 以下。每个归档都是完整、可单独打开的加密单文件，与主文件放在同一目录、使用同一主密码；从左侧「历史归档」点开会自动解锁。也可以在这里手动归档某一年。

导出明文

把全部笔记（含内嵌图片）导出为一个明文 Markdown 文件，保证数据永远可以迁出。注意：导出文件未加密，请妥善保管。
